# StartupSpark AI

An AI-powered startup idea validator. Enter a one-line startup idea 
and get back a full analysis: competitors, market size, revenue 
model, SWOT, MVP suggestions, marketing plan, and risks — like having 
a startup mentor on demand.

## Tech Stack

**Frontend:** React + Vite + Tailwind CSS v4 + Framer Motion
**Backend:** Node.js + Express + Supabase + Groq API (Llama 3.3 70B)
